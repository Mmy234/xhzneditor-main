# 展示端 V1 开发约定

给做 **WPF 播放器壳 + WebView2** 的人。你不画页面，只托管编辑端维护的 Runtime，并加载发布包。配套文档：`Doc/editor-v1.md`。

V1 目标：安装后能跑、能加载发布包、能翻页。单屏触摸查询。不管通讯、安卓、局域网、音频、拓展屏。

---

## 1. 职责

| 做 | 不做 |
|---|---|
| 安装包、开机自启登记、kiosk 全屏 | 画布、属性面板、组件 JSON 设计 |
| 固定目录找包、解密、解压/缓存 | 改 Runtime 页面逻辑 |
| 授权（到期、试用、绑机） | 打开草稿 `.xhzn` |
| WebView2 映射目录、允许自动带声 | UDP/TCP/232/485 |
| 缺资源占位图、加载页、无项目页 | 推送更新、崩溃自拉起 |
| 左上角连点退出、系统音量 | 改系统分辨率、复制屏逻辑 |

Runtime 从编辑端原样拷入安装包。壳不要实现跳页/翻页/视频控件。

建议目录：

```
/player      WPF
/runtime     编辑端维护，构建安装包时打进来
/samples     golden 发布包，本端先吃这个联调
```

---

## 2. 现场怎么用

1. 安装播放器（Win10，安装包自带 WebView2 Fixed Version）。
2. 双击播放器 exe（不要求双击包文件）。
3. 固定目录 **没有** `.xhznpack` → 自带 **无项目页**（选显示器、提示把包拷到哪个目录、显示播放器版本）。
4. 有包 → 自带 **加载页** 拉素材 → 进首页。
5. 一个固定目录一份包，覆盖即换项目。不要做工程列表。

退出回桌面。不要退到「打开文件」对话框。

---

## 3. 只认发布包

| 文件 | 播不播 |
|---|---|
| `.xhznpack` | 播 |
| `.xhzn` 草稿 | **不播** |

包是加密 zip。解开后：

```
manifest.json
project.json
pages/{pageId}.json
assets/**
```

解压到 **包所在固定目录**（安装时定死的项目目录）。`hash` 没变用缓存，变了解压。盘满：中文提示，不要黑屏。体积按 2G 量级考虑。

禁止 `file://` 直接开工程。WebView2 虚拟主机：

| 主机 | 指向 |
|---|---|
| `https://runtime.xhzn/` | 安装目录内 Runtime |
| `https://project.xhzn/` | 本次解压后的工程根目录 |

Runtime 随播放器版本走，不打进工程包。`manifest.schemaVersion` 高于本播放器 → 拒播，提示升级播放器。

JSON 字段以编辑端文档为准。遇到未知字段/未知组件 `type`：**忽略，不要崩。**

## 4. 启动顺序

```
exe 启动
  → 读本机显示器设置（见无项目页）
  → 固定目录有无 .xhznpack
       无 → 无项目页（仍铺在所选屏，不必整套 kiosk 禁键也可，但建议同样全屏）
       有 → 校验 schema / 解密 / 解压或缓存
         → 授权 + 绑机（失败则全屏说明，可退出）
         → 按包配置 kiosk（藏任务栏、禁键、针、开机自启）
         → WebView2 打开 Runtime，传入工程 URL
         → 加载页等素材
         → 进 entryPageId（无钉则 pages[0]）
```

进程声明 **PerMonitor V2 DPI**。按物理像素铺满，不要让 Windows 150% 缩放再乘一次。

---

## 5. 从包里读什么（壳）

完整页面/组件由 Runtime 读。壳至少要读 `manifest.json`：

### 5.1 授权 `license`

```json
"license": {
  "expireDate": "2026-12-31",
  "trialDays": 7
}
```

| 情况 | 行为 |
|---|---|
| 整段 `license` 缺失 | 当试用；画面大大「试用」（Runtime 或壳叠一层均可，要醒目） |
| `expireDate` 已到 | 全屏只显示：`软件已到期 请联系管理员`，不能进内容 |
| `trialDays` | 从 **本机首次成功打开此包** 起算 N 天，到了同一句到期文案 |
| 到期日与试用都配了 | 先到的生效 |
| 换一台电脑 | 拒播（绑机） |
| 用户把系统时间拨回去 | V1 不管 |

绑机：本机指纹存在 `%ProgramData%\XHZN\`（或安装目录配置）。包 id + 机器，首次成功进入加载流程后写入。工程密码 **不要**弹给观众。

### 5.2 播放器行为 `player`

```json
"player": {
  "autoStart": false,
  "cursorVisible": false,
  "exitPassword": ""
}
```

| 字段 | 行为 |
|---|---|
| `autoStart` | `true`：登记当前用户开机启动；`false`：取消登记 |
| `cursorVisible` | 默认当 `false`：全屏藏鼠标。`true` 显示 |
| `exitPassword` | 左上角 **连点 5 下** 弹出密码框。对 → 退出回桌面。空密码：连点后仍允许退出（便于调试） |

音量：播放过程中可以改 **系统音量**（壳做，不要做网页音量条也行）。

## 6. 屏幕与 kiosk

- **单屏。** 显示器在无项目页里选，写入本机配置（例如 exe 旁或 ProgramData 的 `player.local.json` 的 `display` 索引）。编辑器不管现场插哪块 HDMI。
- 窗口无边框，铺满所选屏。
- 画面按设计稿 **拉伸填充**（可变形，V1 就这样）。设计宽高来自 `manifest.design`。
- 藏任务栏。
- 禁止：Win 键、Alt+Tab、边缘滑动（Win10 触摸手势）。
- 不改系统分辨率。复制屏交给显卡，软件不管。
- 触摸和鼠标都要点得动（同一套点击）。

本机才有、不进包：显示器索引、机器指纹、每包首次启动日、解压缓存、日志。

---

## 7. 内置页面（编辑器不画）

### 7.1 无项目页

装完打开、固定目录没有发布包时显示。至少：

- 选显示器（保存后下次用）
- 说明发布包应放到哪个固定目录
- 播放器版本号

有包之后不要再经过这一页，除非包被删掉。

### 7.2 加载页

固定自带。等当前工程素材就绪后进入首页。不要用编辑器里的某一页当加载页。

素材策略交给 Runtime：当前页 + 预载邻页。壳不要一次把 100 页全塞进内存。

## 8. 播放期与 Runtime 分工

壳：

- 把 `https://project.xhzn/` 和窗口逻辑尺寸交给 Runtime（设计分辨率由 JSON 提供；窗口是拉伸后的屏）。
- 左上角连点、密码框、退出 = **WPF**，不要做在网页里（避免被页面元素挡住）。
- 允许自动播放带声音（关闭 WebView2/Edge 对 autoplay 的手势限制）。

Runtime（不要改逻辑，缺了找编辑端）：

- 建页、共用属性、图/字/视频/按钮
- `gotoPage` / `gotoHome`
- 五种翻页：`none` | `fade` | `slideLeft` | `slideRight` | `slideUp`
- 每页闲置；任意点/触重置
- 切页停并卸载上页视频
- 一页多视频可同播
- 缺图缺视频：该位置显示 **播放器提供的固定占位图**（壳把占位图 URL 给 Runtime，或 Runtime 约定一个安装目录内资源名，两端定一个即可，建议 `https://runtime.xhzn/placeholder.png`）

V1 **没有** 通讯桥（无 `host.send` / `onFrame`）。

## 9. 包内页面契约（只读摘要）

细节以编辑端文档为准。壳一般不 parse 组件，但联调、占位、拒播要知道这些：

- 组件 type：`image` | `text` | `video` | `button`
- 图片：jpg/png
- 视频：`src` 数组，`loopMode`：`once` | `single` | `list` | `interval`，默认可带声自动播
- 动作：`gotoPage` + `pageId`，或 `gotoHome`；可选 `transition`
- 闲置：`idle.seconds === 0` 为关

损坏的包、解密失败、绑机失败：全屏大字说明 + 仍能用退出手势离开。不要静默黑屏。

---

## 10. 日志与失败

- 文件日志即可（建议 `%ProgramData%\XHZN\logs\`），V1 不要做日志界面。
- 缺图/坏视频：占位图，继续播，写日志。
- 崩溃自动重启：V1 不做。
- 授权失败/过期：固定文案，不能进内容。

---

## 11. 安装与环境

- 目标系统：Windows 10（11 能装也可，合同按 Win10）。
- 安装包自带 WebView2 **Fixed Version**，不要依赖机器 Evergreen Edge 版本。
- 安装包打入：exe、Runtime、占位图、加载页/无项目页资源。
- 绿色免装：V1 不做，只要安装包。

建议本机路径（可改，但要在无项目页写清楚）：

```
安装目录\
  Player.exe
  runtime\
  placeholder.png
项目目录\          ← 固定，用户只往这里丢 .xhznpack
  xxx.xhznpack
  _cache\          ← 解压缓存
```

---

## 12. V1 明确不做

音频；网页组件；PPT/PDF；通讯；局域网推送；Android；拓展多窗；复制屏渲染；改显示器分辨率；崩溃看门狗；工程列表；双击包文件打开；推送热更新。

---

## 13. 本端验收

先用 `samples` 手写/编辑器出的 golden 包，不依赖编辑器 UI 做完。

1. 刚装完、目录无包：看到无项目页，能选屏。
2. 包拷进固定目录，双击 exe：加载页 → 首页。
3. 点按钮/图片跳页、回首页、翻页动画、视频带声。
4. 闲置跳转；切页后上页视频停。
5. 缺一张图：占位图，其它还能点。
6. 无 `license`：大字「试用」仍能播。
7. 到期或试用用尽：只见「软件已到期 请联系管理员」。
8. 换机（或清指纹后当换机测）：绑机拒绝。
9. 左上角连点 5 下，密码对，回桌面。
10. 第二次打开同包：走缓存，更快且画面一致。
11. 包 `schemaVersion` 故意调大：拒播并提示升级。

对接编辑端时，以包内 JSON 为准，不要口头对字段。
